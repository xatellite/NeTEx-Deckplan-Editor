# NeTEx deckplan standalone editor

Vue application using Vite, Tailwind CSS, and Bun.

## Setup

From project root:

```sh
bun install
cd library
bun run build
cd ../components
bun run build
cd ../standalone
bun run dev
```

## Development

Run these commands from `standalone/`:

```sh
bun run type-check
bun run build
bun run dev
```
